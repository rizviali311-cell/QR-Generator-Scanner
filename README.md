# QR Generator & Scanner

A professional, high-performance web application to generate custom QR codes and scan them using your device's camera.

## Features
- **Instant Generation**: Create QR codes from any text or URL.
- **Customization**: Change the size and color of your QR codes.
- **Live Scanner**: Use your camera to scan and decode QR codes instantly.
- **History Management**: Keep track of your previous activities (stored locally).
- **Download & Share**: Download your generated QR codes as PNG images.
- **Smart URL Detection**: Automatically opens links after scanning.

## Technologies Used
- **HTML5 & CSS3** (Tailwind CSS for styling)
- **JavaScript** (ES6+)
- **qrcode.js**: For high-quality QR code generation.
- **html5-qrcode**: For robust camera scanning functionality.

## How to Run
1. Clone the repository.
2. Open `index.html` in your browser.
3. *Note: For the scanner to work, you must host it via HTTPS or run it on `localhost` (e.g., using VS Code Live Server).*
